# Mao-Term

A modern terminal for Windows and Linux, written in Rust and rendered on the GPU.

- ⚡ Fast and light: on-demand rendering, 0% CPU when idle.
- ✨ Autocomplete as you type.
- 🗂️ Tabs, split panes and a sidebar with a file tree.
- 📄 Built-in document viewer.
- 🤖 Panel showing the AI agent sessions running on your machine.
- 📊 System performance monitor.

> Status: **early development**. See [`docs/roadmap.md`](docs/roadmap.md).

## Documentation

Start at [`docs/README.md`](docs/README.md). If you are a coding agent, read [`AGENTS.md`](AGENTS.md).
